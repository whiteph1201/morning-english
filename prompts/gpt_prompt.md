# ChatGPT에 붙여 넣을 요청문 (반자동 방식)

매달 한 번, 아래 순서대로 ChatGPT에 요청하세요. 결과는 GitHub 저장소의
`incoming/YYYY-MM/` 폴더에 part1.json, part2.json, part3.json 으로 저장합니다. (YYYY-MM = 만들 달, 예: 2026-12)

---------------------------------------------
## 1단계: 처음 한 번 (복사해서 붙여 넣기)

너는 가족용 영어 학습 페이지의 콘텐츠 작성자야. 아래 형식과 기준을 정확히 지켜서 JSON만 출력해.

(여기에 prompts/rules.md 파일 내용을 전부 붙여 넣기)

지난 주제 목록(겹치지 않게):
(여기에 지난 주제 목록을 붙여 넣기: 브라우저에서 config.js 의 주소 뒤에 m/history.json 을 붙여 열면 보입니다.
 예: https://abcdefgh.supabase.co/storage/v1/object/public/english/m/history.json)

먼저 30일치 계획만 표로 보여 줘: 날짜, theme(어린이 주제), ad.t(성인 상황). 지난 주제와 겹치지 않게.

---------------------------------------------
## 2단계: 계획이 마음에 들면

1~10일차를 위 형식대로 만들어 줘. {"days":[ ... 10개 ... ]} 형태의 JSON만 출력해.

→ 결과를 incoming/YYYY-MM/part1.json 으로 저장

## 3단계

같은 형식으로 11~20일차. → part2.json

## 4단계

같은 형식으로 21~30일차. → part3.json

---------------------------------------------
세 파일이 모두 올라가면 GitHub이 자동으로 형식을 검사하고, 원어민 음성을 만들어 Supabase에 올립니다(30~60분). 홈페이지에는 바로 반영됩니다.
Actions 탭에서 빨간 X가 보이면 눌러서 오류 내용을 확인하고, 그 내용을 ChatGPT에 보여 주며 고쳐 달라고 하세요.
