# 콘텐츠 형식과 기준 (아침 영어 한 장)

하루치(day) JSON 형식:
{
 "theme": "어린이 탭 공통 주제 (한국어, 짧게)",
 "sub": "주제 한 줄 설명 (한국어)",
 "g3": {"w": [단어카드 3개], "e": [표현 3개], "d": [대화 2줄]},
 "g6": {"w": [단어카드 5개], "e": [표현 3개], "d": [대화 6줄]},
 "pa": {"w": [일상 필수 단어카드 5개], "e": [부모 생활영어 표현 5개], "d": [대화 6줄]},
 "ad": {"t": "성인 상황 제목 (한국어)", "s": "상황 한 줄 설명 (한국어)", "k": [핵심 표현 5개], "d": [1분 대화 14줄]}
}
단어카드 = ["이모지", "영어 단어", "한국어 뜻", "단어 한글 발음", "영어 예문", "예문 한국어 뜻", "예문 한글 발음"]
표현     = ["영어", "한국어 뜻", "한글 발음"]
대화 줄  = ["영어", "한국어 뜻"]   ← A, B가 번갈아 말함 (1, 3, 5…번째 줄이 A)

기준:
- 초3(g3): 아주 쉬운 단어, 3~5단어 문장. 그림으로 표현하기 쉬운 구체적 단어. 이모지는 단어 뜻과 맞게.
- 초6(g6): 6~10단어 문장. 6줄 대화가 자연스럽게 이어질 것.
- 부모(pa): 부모가 아이에게 실제로 쓰는 생활영어. 부모-아이 대화 6줄. 집·생활 필수 단어 5개.
- 성인(ad): 초중급. 문장 8~12단어. 실생활 상황(직장, 가게, 병원, 여행, 이웃, 전화 등). 14줄, 약 1분 분량.
- 같은 날 g3, g6, pa는 같은 주제(theme)를 공유한다. 성인 상황(ad.t)은 별개로 정한다.
- 대화는 앞줄에 자연스럽게 이어지고, A/B 역할이 중간에 바뀌지 않는다.
- 한글 발음은 실제 소리에 가깝게, 영어 단어 단위로 띄어 쓴다. 예: "렛츠 고 투 더 파크"
- 영어 문장 안에 큰따옴표(")를 쓰지 않는다. 작은따옴표(')는 괜찮다.
- 출력은 JSON만. 설명 문장이나 ``` 표시를 붙이지 않는다.
